# Social Engineering & Phishing Campaign Simulation – GRC Lab

## Project Overview

This project explores the human element of cybersecurity risk through a controlled social engineering and phishing simulation.

The lab focuses on understanding phishing attack mechanics, measuring user susceptibility, evaluating security awareness controls, and translating simulation results into actionable Governance, Risk and Compliance (GRC) recommendations.

The practical exercise uses GoPhish within GitHub Codespaces to simulate a controlled phishing campaign against a test environment.

## Objectives

- Understand the mechanics of phishing attacks.
- Configure and operate the GoPhish framework.
- Conduct a controlled phishing simulation.
- Measure email open rates and link click-through rates.
- Assess simulated credential-submission attempts without collecting real credentials.
- Calculate and interpret phishing risk metrics.
- Evaluate existing security awareness controls.
- Develop evidence-based recommendations for management.

## Environment and Tools

- GitHub Codespaces
- Linux terminal
- GoPhish
- Mailtrap (test email delivery)
- Markdown documentation

## Project Scope

This is an authorised educational simulation. Testing is restricted to controlled test accounts and environments. No unsuspecting users or real organisational credentials are targeted or collected.

## Key GRC Focus Areas

- Human risk assessment
- Security awareness and training effectiveness
- Risk identification and evaluation
- Security control effectiveness
- Risk treatment recommendations
- Executive reporting
